# Where the glyphs come from

`masks.png` holds six forms of 羊, one per 384 px cell, built by `../tools/make_masks.html`.

| Cell | Form | Source | License |
|---|---|---|---|
| 0 | Oracle bone | `src/oracle.svg`, Wikimedia Commons `羊-oracle.svg` | Public domain |
| 1 | Bronze (Western Zhou) | `src/bronze.svg`, Wikimedia Commons `羊-bronze.svg` | Public domain |
| 2 | Small seal | `src/seal.svg`, Wikimedia Commons `羊-seal.svg` | Public domain |
| 3 | Clerical | `src/clerical.svg`, Wikimedia Commons `Character Yang2 Cler.svg` | Public domain |
| 4 | Modern | Noto Sans SC Light, drawn from the font | SIL Open Font License 1.1 |
| 5 | Pixel | DotGothic16 at its native 16 px, drawn from the font | SIL Open Font License 1.1 |

Also kept in `src/` and not used yet: `bigseal.svg` (`羊-bigseal.svg`) and `bronze-shang.svg`
(`羊-bronze-shang.svg`), both public domain on Wikimedia Commons.

Commons files live under `https://commons.wikimedia.org/wiki/File:<name>`.
